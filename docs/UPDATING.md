# Updating the portfolio

## Add a project

1. Copy `PROJECT_TEMPLATE.md` to a new file in `projects/`.
2. Add images to `assets/images/` and CAD or other supporting files to an appropriate assets folder. Use short filenames without spaces.
3. Add a relative link in the README project table.
4. Record the project’s source and team credit in `docs/sources.md`.
5. Update the presentation if the project should appear in the shorter overview.

## Before sharing

Open the README and follow the project and download links. For every performance number, preserve the units, trial size, and test conditions. Label proposed features clearly. Credit shared work and identify your own contribution.

The repository is currently private. Only people with access can open its GitHub links. To share the portfolio without repository access, send the PDF.

## Work toward stronger evidence

Add the SPIS source repository and a short chess-camera demo. Record robot trials and preserve the RobotC source. Add physical fabrication photos where available. Confirm your specific role in the cooler project before promoting it to the main project table.
